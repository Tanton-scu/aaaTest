# 代码风格说明

V5 新增主链代码模仿 PriEvO 的朴素风格：普通函数默认不写类型注解，以 class、def、dict、list、if、for 为主。FastAPI/Pydantic 为生成 schema 保留必要 annotation。

重要逻辑使用中文注释解释原因，例如预算为何在短事务中预留、Redis 为何失败降级、checkpoint 为何校验 Dataset digest。日志面向人时使用中文，`run_id`、`dataset_id`、Event type、DB field 和正式算法术语保持英文。

旧 V4 模块仍有 Protocol、frozen dataclass 和较多 typing。重构原则是主链替换到哪里就简化到哪里，不进行会掩盖语义变化的全仓机械删注解。新增 `datasets/`、`algorithm/`、MySQL/Redis adapter 与 scripts 已优先使用简单签名。
