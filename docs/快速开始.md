# 快速开始

## Docker Full Mode

```powershell
Copy-Item .env.example .env
docker compose up --build
docker compose ps
```

打开 `http://localhost:8000`。`.env` 中的 LLM 三项可全部留空，此时使用 FakeLLM；只填写一部分会拒绝启动。三项完整时，Similarity、Heuristic Generation、Prior Research、Repair 与 Final Selection 使用真实 OpenAI-compatible HTTP adapter。

常用配置：

```text
AGENT_MEMORY_TTL_SECONDS=86400
AGENT_MEMORY_MAX_ITEMS=30
FULL_MODE_SMOKE_TIMEOUT_SECONDS=600
FULL_MODE_SMOKE_WORKER_READY_TIMEOUT_SECONDS=30
```

验证：

```powershell
Invoke-RestMethod http://localhost:8000/api/health
Invoke-RestMethod http://localhost:8000/api/datasets
docker compose exec -T app python scripts/full_mode_smoke.py
```

查看某个 Run 的 Agent Trace：

```powershell
Invoke-RestMethod "http://localhost:8000/api/runs/<run_id>/agent-trace"
```

## 本地 Demo/Test

```powershell
python -m pip install -e ".[research,papers,test]"
python scripts/run_demo.py
python scripts/agent_harness.py
python -m unittest discover -s tests -v
```

Demo 使用 SQLite；Full Mode 使用 MySQL/Redis。两者共用 `PriEvOEngine -> PersistentEvolutionRuntime -> DurableAgentCoordinator` 主链。Full smoke 有全局截止时间，并会在首个 Job 长时间无人领取时提示检查 worker；不会无限等待。
